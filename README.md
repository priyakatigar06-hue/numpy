# NumPy Basics & Fundamentals

A clean, hands-on introduction to fundamental array operations using **NumPy** (Numerical Python). This repository covers array creation, type casting behavior, shape inspection, element-wise arithmetic, slicing, boolean indexing, and matrix reshaping.

---

## Key Features & Concepts Covered

- **Array Creation & Type Coercion:** Creating 1D/2D arrays and observing automatic type casting (e.g., string coercion).
- **Special Initializers:** Generating matrices initialized with zeros using `np.zeros()`.
- **Shape & Dimensionality:** Checking matrix dimensions using `.shape` and `type()`.
- **Element-wise Arithmetic:** Vectorized operations like element-wise multiplication.
- **Slicing & Boolean Masking:** Extracting sub-arrays and filtering elements based on conditional criteria (`arr[arr > threshold]`).
- **Reshaping:** Reorganizing array structures with `np.arange()` and `.reshape()`.
